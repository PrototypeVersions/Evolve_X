# Evolve_X

An open blueprint for a people-owned AI cooperative: member-owned computing, AI that works for its members, and a share of the surplus that grows as the network grows. Planned to start in Dallas–Fort Worth and Amarillo, designed so any town can open the next chapter.

Live site: https://prototypeversions.github.io/Evolve_X/

## The sheets

| Page | What it covers |

## Design

Version 0.2 uses a "luminous engraving" look: the guilloché, iris inks and wave lines of banknotes and share certificates, drawn as light on night ink, with reading sections on pale security paper. Every seal is generated in the browser from a seed, so each pillar and page has its own. Motion is limited to the seals slowly turning, the flywheel pulse and the Texas chapters lighting in order, and all of it stops for visitors who ask for reduced motion.

The first design (version 0.1) is preserved on the `First_Evolve_X` branch.

## Editing

Plain HTML, CSS and JavaScript with no build step. Shared styles live in `assets/style.css`; the seals, wave lines, mobile menu and calculator live in `assets/site.js`. The header and footer are repeated on every page, so change them in all eight files.

GitHub Pages serves the site from the root of the `main` branch.
