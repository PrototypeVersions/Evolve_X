# Evolve_X

An open blueprint for a people-owned AI cooperative: member-owned computing, AI that works for its members, and a share of the surplus that grows as the network grows. Planned to start in Dallas–Fort Worth and Amarillo, designed so any town can open the next chapter.

Live site: https://prototypeversions.github.io/Evolve_X/

## The sheets

| Page | What it covers |
| --- | --- |
| `index.html` | The blueprint at a glance |
| `vision.html` | Where AI is taking the economy, who gets the income, centralization vs. decentralization, the public AI dividend |
| `model.html` | How the co-op earns, pays and returns surplus, with an interactive chapter calculator |
| `pillars.html` | Own, Work, Share, Protect, Settle, Create, Learn, Home |
| `charter.html` | Governance, anti-drift rules, lines the co-op won't cross, AI accountability |
| `roadmap.html` | Phases from one hub to a national federation, risks, published measures |
| `questions.html` | Plain answers to the hard questions |
| `origins.html` | How each idea from Rousix and the Intermetanet was kept, reshaped or retired |

## Editing

Plain HTML, CSS and JavaScript with no build step. Shared styles live in `assets/style.css`; the seal drawing, mobile menu and calculator live in `assets/site.js`. The header and footer are repeated on every page, so change them in all eight files.

GitHub Pages serves the site from the root of the `main` branch.

## Critique
